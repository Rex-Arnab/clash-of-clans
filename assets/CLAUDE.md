# assets/ — perception ground truth

Inherits the root [`CLAUDE.md`](../CLAUDE.md).

## Purpose

The pixels the harness matches against. These files are **data with contracts**, not incidental
binaries — every one of them is bound to a specific screen geometry, density and game version.

## Ownership

| Path                                          | What it is                                                                                                                                                                      |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `templates/manifest.json`                     | the binding record: game version, `[2392, 1080]`, density 360, cut date, and per-template method / threshold / measured margins. Read by `templates.assert_manifest_matches()`. |
| `templates/loot_bubble.png` + `_mask.png`     | the shared bubble frame; the ring mask excludes the interior icon.                                                                                                              |
| `templates/dlg_reload_game.png`               | the inactivity-disconnect dialog, with `tap_offset` `[94, 25]` to the Reload button.                                                                                            |
| `digits/labels.json`                          | **the ground truth.** Sample filename → true value of each HUD counter.                                                                                                         |
| `digits/samples/*.png`                        | full-frame landscape screenshots, one per label entry.                                                                                                                          |
| `digits/atlas.npz` + `atlas.json`             | generated by `scripts/build_digit_atlas.py`. Do not hand-edit.                                                                                                                  |
| `models/burnt_yolov5s_26cls.onnx`             | the local defence detector read by `coc/vision/yolo.py` (sha256-pinned). Third-party, **no license** — never redistribute.                                                      |
| `models/labels.json` + `models/samples/*.png` | crop-graded ground truth for `tests/test_yolo.py`: every true Air Defense / X-Bow / Inferno the detector boxed on each sample.                                                  |

## Local contracts

- **The manifest is a gate, not documentation.** If you cut templates on different geometry or
  density, update `screen`/`density` — and understand you have invalidated every existing template,
  because scale drift makes taps land plausibly but wrongly with no error.
- **Every template carries its measured margin.** For `loot_bubble`: true matches 0.00–0.143 against
  a first false positive at 0.196, threshold 0.15. A new template without a measured true-vs-first-
  false-positive number is not finished.
- **A mask is a separate `<name>_mask.png` next to the template**; `templates._load()` picks it up by
  convention. Masked matching is required for anything sitting on the animated village.
- **`labels.json` is truth; the atlas is derived.** Adding a sample means: drop the full-frame
  landscape PNG in `samples/`, add its exact counter values to `labels.json`, re-run the builder,
  re-run pytest. Never edit `atlas.npz`.
- **Samples must be native landscape 2392x1080 full frames**, not crops — the builder segments them
  through the same `RESOURCE_ROIS` the runtime uses, which is the point.
- **A label mismatch is a hard error, never a partial import.** If segmentation finds a different
  glyph count than the label's length, the builder refuses the whole run rather than zipping a short
  list against a long label and poisoning the atlas with mislabelled glyphs.
- **Digit coverage is uneven by design and it is fine.** Current counts range 2 (`6`) to 15 (`3`).
  A missing digit causes `UnreadableNumber`, not a misread — that is the intended failure.

## Work guidance

- Fresh frames come from a real run: `python3 -m coc.cli collect --dry-run` writes `00_before.png`
  and `99_after.png` into `runs/<stamp>_*/`. Copy from there rather than taking an ad-hoc screencap,
  so the sample went through the same canonicalisation path.
- Cutting a bubble/dialog template: crop from a real frame, build the mask so **only** the element's
  own pixels are white, then measure the score against a true match and against the best false
  positive elsewhere on the frame. Record both in the manifest.
- Reading a screenshot you captured? Compress it to `/tmp` first (see the global `IMG_COMPRESS_*`
  rules) — a raw frame here is ~2.2 MB.

## Verification

```bash
python3 scripts/build_digit_atlas.py    # must print no ERRORS and no MISSING DIGITS
python3 -m pytest tests/ -q             # every labelled sample reads exactly
```

Template changes additionally need a live `collect --dry-run` proving the new template fires on the
real screen and nothing else regressed.

## `models/` — local detector weights and their ground truth

- **The .onnx is data with a contract, like a template.** Exported 2026-09-17 from
  BurntBaseTeam/clash-of-clans-object-detection-api `best.pt` (YOLOv5s, 26 classes) with the
  ultralytics/yolov5 repo at commit 402e17dd: `export.py --include onnx --imgsz 800 --opset 12`.
  `yolo.WEIGHTS_SHA256` refuses any other file, because every graded number is for this export.
  Survey, grading sheets and scripts: `scratchpad/yolo_survey/`.
- **`labels.json` truth is crop-graded, never counted.** Each entry is a box the detector returned
  that a human confirmed at native resolution. Adding a sample: drop a full native 2392x1080 frame
  in `samples/`, run `yolo.detect()`, crop EVERY returned box, and record only the true ones with
  their `centre` and `conf`.

## `bb_defenses.json` — Builder Base defence knowledge base

Game facts, not perception data: every Builder Base defence and trap with
`targets` (ground / air / both / none), range in tiles, size, counts per Builder
Hall level, and the tactical notes that follow from them. Sourced from the wiki
one page at a time on 2026-09-09.

- **Nothing here is guessed.** Unconfirmed fields are `null`; the Cannon carries
  an explicit caveat that only the HOME VILLAGE page was captured, so its
  Builder Base range and counts are marked unconfirmed.
- Read it through `builder_base.load_defences()`; `threatens(unit)` and
  `free_targets(unit)` answer the two questions a planner actually asks.
- The X-Bow is `mode_dependent` (ground XOR air) and `threatens()` deliberately
  returns it for BOTH units — it fails closed rather than guessing a mode.
- `_perception_limits` records what no classifier can ever see (Hidden Teslas
  and all traps are invisible until triggered). Read it before trusting any
  "safe route" computed from a frame.
